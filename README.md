# Component library

A reusable component library for TÍNT, our group project (Hopverkefni 2), with a Storybook demo where every variant can be toggled.

- `src/tokens.css` holds every shared colour, font size, spacing and radius.
- `src/components/` holds one folder per component: the component, its CSS and its stories.

Run `npm run storybook` to see every component and toggle its variants.
